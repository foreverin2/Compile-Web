# Compile Web — 《译世界》网页版

把桌游 **Compile（译世界）**（Jeux Synapses Games Inc.，©2024/2025）实现为**纯前端、无后端**的网页游戏：打开即玩，可安装、可离线，对局档案可导出、可在另一台设备上**逐步重放**。热座双人已经完整可玩，联机所需的会话层与档案格式都已就位。

> ⚠️ 本项目为个人学习 / 自用项目。官方规则与卡牌文本受版权保护（Jeux Synapses Games Inc.），请勿公开分发或商用。

## 亮点

### 🎞️ 一局一档案，档案能重放
每局都能导出成一份自包含档案（种子 + 开局配置 + 每一步操作）。把它拿到另一台设备导入，就能**逐步重演这一局**——可暂停、单步、1×/2×/4× 倍速。同一份数据格式还同时承担「存档 / 录像 / 断线重连凭据」。

### 🔒 无后端、不联网、数据只在你手里
整个项目**没有任何网络请求代码**（`fetch` / `XMLHttpRequest` / `WebSocket` / `RTCPeerConnection` 全仓零命中）。昵称、设置、卡组这些轻量偏好，只有在你于首次进入的授权弹窗里选择「允许」之后才会写进你自己的浏览器存储；选择「不用」就是**游客模式**——所有数据只在内存，刷新即全丢。随时可在「本地数据与隐私」屏一键清除。

### 📴 可安装、可离线、可一键更新
手写的 Service Worker + manifest：装到桌面/主屏像原生应用；断网也能打开；发新版本会提示并可一键更新。预缓存只收**程序外壳**（实测 11 个文件 / 1.1 MiB），卡图等你用到时才进运行期缓存。

### ⚡ 极轻
**零运行时依赖**：`package.json` 里没有 `dependencies`，只有三个开发期工具（TypeScript / Vite / Vitest）。PWA、稳定哈希、文件读写全部手写或复用语言内置能力。

### 🎯 确定性与可验证性
引擎是**确定性**的：随机数由种子驱动并写进状态，任何一步之后都有稳定的「状态指纹」。因此可以做到——同种子 + 同操作 ⇒ 同结果；录一局再重放 ⇒ 逐字节对得上。配套的测试里包含随机对局模糊测试、录制-重放往返、以及一个用真 Chrome 校验**真实布局与层叠**（而不是读样式表）的自查工具。

## 运行方式

```bash
npm install        # 安装开发期依赖（TypeScript / Vite / Vitest）
npm run dev        # 开发服务器（Vite）
npm run build      # 类型检查 + 生产构建 + 生成 Service Worker 版本戳 → dist/
npm run preview    # 预览构建产物
npm run test       # 运行测试（Vitest，148 个文件 / 1891 项）
npm run texts:check # 卡牌文本与官方文本的差异自查（应为 0 处差异）
```

> 发布请用 `npm run build`（它会额外生成 Service Worker 的版本戳，`npx vite build` 不会）。

## 技术要点

- **分层严格单向**：`src/core`（纯引擎，零 DOM）→ `src/app`（纯逻辑：档案格式、本地存储、会话层驱动）→ `src/ui`（DOM 渲染与特效）→ `src/main.ts`（装配）。有常驻测试守卫这条依赖方向与「纯逻辑层不碰浏览器 API」。
- **会话层驱动**：动作只有一条执行路径（唯一入口 `driver.submit`）。热座用 `LocalDriver`，档案重放用 `ReplayDriver`（只读闸门：只放行档案里的下一条操作），将来的联机只需再换一个 `NetDriver`。
- **重放复用现场编排**：重放不是另写一条捷径，而是把档案里的每一步喂进与现场完全相同的动作编排，因此特效、错误守卫、动画时序一并复用。
- **行为腿 > 文本腿**：需要判断「谁盖住谁 / 能不能点到」时，用 `elementFromPoint` 问真实浏览器，而不是读 `getComputedStyle`。
- **守卫即规格**：关键不变量（唯一入口、重放只读、档案纯逻辑、隐私边界文案、文档结构）都有测试钉住，并且每条新守卫都要用「注入缺陷 ⇒ 必须变红」的方式验证过牙口。

## 项目结构

```
src/
├── core/            # 纯引擎（零 DOM）：模型、牌库、回合状态机、规则、效果、事件总线
│   ├── models/      #   Card / Protocol / Player / GameState
│   ├── engine/      #   牌库操作、回合状态机
│   ├── rules/       #   编译判定、控制权、限制
│   ├── effects/     #   卡牌效果解析与结算（45 套协议）
│   ├── fingerprint  #   状态指纹（联机与重放的比对基准）
│   └── game.ts      #   门面：合法动作 / 执行动作 / 胜负
├── app/             # 纯逻辑（不碰浏览器 API）：档案格式、卡牌指纹、本地存储、会话层驱动
├── ui/              # DOM 渲染与特效（热座页 / 远程对局页 / 重放控制条 / 各种整屏）
├── data/            # 卡牌与协议数据（270 张卡的真实中文文本）
└── main.ts          # 应用装配（页面路由、动画编排、授权与本地数据接线）
tests/               # 单元测试、确定性测试、行为腿与守卫（148 文件 / 1891 项）
tools/               # 开发期自查工具（卡牌文本同步、真实浏览器真值自查）
docs/                # 设计稿、分阶段实现计划、各阶段收口文档
public/              # manifest、手写 Service Worker、图标
```
