## 零、P4：英文模式不产出卡牌中文翻译文本框

用户 2026-10-01 原话：「英文的卡牌文本不用管，因为**卡牌图片的原文就是英文**，如果设置为了英文，
只需要**不显示中文翻译文本框**即可」。

```ts

  if (getLang() === 'en') return null;   // ★ P4：en 不产出这一层
  ...

```
