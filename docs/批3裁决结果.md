- **[Q3] time-1** 「翻转1张被覆盖的卡牌」：**任意被盖住的卡**（含被盖正面卡翻成反面与被盖反面卡翻正）。**同时修正批1 chaos-0：目标也是任意被盖卡**（非仅反面）——chaos.ts 已改 coveredCandidates（2026-09-05）。
- **[Q5] time-3**：**随机揭示**弃牌堆 1 张（非自选）→ 正面朝下打到其它链路（非 time-3 所在线，目标线自选）。
- **[Q6] diversity-0**：场上有 6 张不同协议卡 → 自己的多元协议**纯翻面** compiled=true（不删卡不抽牌无编译连锁）。
- **[Q7/8/9] diversity-1/4/6 口径**：不同协议的卡牌数 = 去重协议数（diversity-1=该线双方堆叠去重；4/6=全场合计去重）；阈值现时值（Q6 全局口径）。
- **[Q10] assimilation-0**：取对手场上面朝下卡（含被盖）**加入自己手牌，所有权变更**。
- **[Q11/12] assimilation-2/6**：跨方牌库顶 → 反面打到对方堆叠（assimilation-2=对手牌库顶打到自己堆叠 / 6=自己牌库顶打到对手一侧），**卡所有权变更**（离库入对方场）。

- **[Q15] unity-0**：中=场上有其它统一牌时「翻转或抽取1张牌」二选一；底=before-covered 且覆盖者为统一牌时同二选一。
- **[Q16] unity-4**：无手牌时揭示牌库（deckReveals whole）→ 抽所有统一卡 → 切洗。
