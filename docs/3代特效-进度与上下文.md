  **批次 C（抽牌/反面打出/编译后）需要新事件分支**：`card:drawn` / `card:deck-played` / `card:hand-played` / `line:compiled`
  —— 同样往 `GEN3_CARD_FX_API` 加能力、往 switch 加首行接管即可（保持"基础动画照常"）。
- **两条踩过的坑（务必守）**：
  1. **浮层卡自身 background / ::before 会被卡面 `<img>` 盖住** → 卡面覆盖类视觉一律走 `::after` 或子元素；
  2. **浮层卡类上不要做 transform 动画**（会覆盖横置卡 rot-cw/ccw 的内联 rotate，卡会"立起来"）
     → 位移感交给子元素/伪元素（粒子用 `--dx/--dy`，角度用 `--r` + keyframes 里的 `rotate(var(--r))`）。
- **多张连锁编排**：`queueStaggered(key, sortKey, run, {windowMs, gapMs, onAllDone})` —— 同一批（40ms 窗口）
  按 sortKey（到线中心距离）排序，逐张错开；新星0 整线删除 = 70ms、愤怒2 整线翻转 = 80ms。
- **跨卡连线/弧轨**：`arcTrack(fromRect, toRect, cls, proto, dots, ms, z, ribbon, api)` —— body 级满屏 SVG path
  ＋ `offset-path: path(...)` 光点，用于新星引力线、傲慢金弧、新星星轨、柔性飘带。
- **守卫测试**：`tests/ui/gen3-card-fx.test.ts`（覆盖范围不得擅自扩大 / 类名↔CSS / 分发点已接入 / 基础动画未被替换 /

## 6. 约定（写代码时必须遵守）

0. **范围红线（2026-09-13 决定）**：**只给"点名的触发点"加特效**（设计稿 §4.1~§4.15 + 柔性3/支点1·3 交换附加层）。**其余 3 代卡牌触发时只播基础动画**——不要"顺手"给别的卡加特效；发现漏项先问，不要自行扩范围。
1. **叠加不替换**：基础动画永远照播，协议特效只加层。
2. **常驻 vs 瞬态分家**：持续生效走 `sync*`（复用节点、不重建）；单次触发走事件订阅 + 301 浮层。
3. **品质七要件**（设计稿 §8.1）：层次合成 / 材质 / 物理感 / 三阶配色 / 起止衔接 / 与基础动画咬合 / 可读性；**禁止清单见 §8.2**。
4. **Q6：全部完整特效，不降级**；必要时只用"错开时间"。
5. 术语：位移指令统一叫**偏转**（`shiftTerm()` 恒返回"偏转"）。
6. 验证门槛：`tsc` 0 错 + `vitest` 全绿 + `vite build` 成功 + `texts:check` 差异 0。
