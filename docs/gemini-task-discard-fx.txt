# Gemini 生成任务单：卡牌「弃牌」特效（对角线切割）

> 用法：把本文件内容发给 Gemini，生成物按「交付路径」放回项目。

## 任务
为一个纯 HTML/JS 网页卡牌游戏生成「弃牌」特效代码：卡牌被弃置时，卡面**沿对角线切成两半**，两半分离滑开并逐渐消失。这是所有协议的通用基础特效（Fire 协议另有专属火焰特效，互不影响）。

## 技术规格
- 交付格式：**纯 CSS + 原生 JS**（无框架、无外部依赖、免插件）
- 文件命名与交付路径：
  - `public/assets/fx/discard-cut.css`
  - `public/assets/fx/discard-cut.js`
- 导入方式：CSS 由 `index.html` 以 `<link>` 引入；JS 由宿主（`src/ui/effects/index.ts`）`import` 并调用
- 动画时长：**≤ 1.2s**，单次播放（非循环）

## 宿主集成契约（必须遵守，宿主按此调用）
1. 触发时，宿主把被弃卡牌克隆到 `document.body` 级浮层（`position: fixed` 定位到原卡位置，`pointer-events: none`），克隆节点保留 `.card` 类与卡面图片子节点，**不含交互按钮**。
2. 宿主在克隆节点上调用你提供的挂载函数，例如：
   ```js
   import { mountCut } from '/assets/fx/discard-cut.js';
   mountCut(cardCloneNode); // 内部给节点加 .card-cut 类 + 生成两半并启动动画
   ```
3. 你提供的 JS 需**把卡面沿对角线切成两半**：建议复制卡面内容为两个三角形半片（用 `clip-path: polygon(...)` 裁剪：上半三角形 = 左上+右下对角线的其中一侧，下半三角形 = 另一侧），两半各自独立运动。
4. **动画结束由宿主负责移除**（约 1.2s 后），你的代码只需保证动画在 1.2s 内自然结束，不要自己移除节点。
5. 不要在代码里引入任何网络资源、字体、图片。

## 视觉描述
- 切割方向：**沿卡牌对角线**（建议左上 → 右下；如实现方便，也接受右上 → 左下，二选一并固定）
- 切割瞬间：沿切割线出现一道白色/青色细闪光（0.1~0.15s），暗示"刀切"；随后两半沿对角线法线方向**反向分离滑开**（上半片向左上滑出、下半片向右下滑出），同时各自轻微旋转 3~8°
- 两半分离过程中透明度渐隐至 0，末端可带 1~2 粒细碎光点（数量 ≤ 10）
- 配色与氛围：冷色系（青蓝白）闪光，契合游戏的赛博/程序代码风格（现有 UI 主色 #4ff0ff 青、#0a0e1a 深底）；不要用火焰橙红色（那是 Fire 协议专属）

## 约束
- 无需真实美术功底，简洁可用即可；所有尺寸相对卡牌节点自适应（用 % 或基于节点尺寸计算）
- 无外部依赖/免插件；动画时长 ≤ 1.2s；不自己移除节点；不触碰宿主逻辑
- 代码注释用中文

- [ ] `discard-cut.js`（`export function mountCut(node: HTMLElement): void`，内部生成两个三角形半片、挂载覆盖层、启动动画）
