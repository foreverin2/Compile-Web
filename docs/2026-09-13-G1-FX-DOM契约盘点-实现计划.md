## 为什么 G1 必须做、且必须分清三类

`src/ui` 约有 150 处 `querySelector*` / `closest`。**天真的做法是把它们全列成"契约"**，那样 G2 会被要求让远程页提供 `.gen3-wrath-spark-wrap`、`.fx-love-heart` 这类**特效自己创建的子节点**——这既不可能也没意义。

真实的三类必须分开：

| 类 | 含义 | 谁负责提供 | 例子 |
|---|---|---|---|
| **A 结构钩子** | 渲染器产出、特效**只读**用于定位 | **渲染器**（G2 的远程页必须提供） | `.stack-slot[data-player][data-line]`、`[data-uid]`、`.deck[data-player]` |
| **B 特效自建节点** | 特效层自己 `createElement` 出来的节点，后来再 `querySelector` 取回 | 特效层自己 | `.gen3-*-wrap`、`.fx-love-heart`、`.reveal-wings` |
| **C 内部注册键** | 挂在元素上的 `dataset.*`，特效用来记账（去重/防重入） | 特效层自己 | `dataset.warBladeKey`、`dataset.iceLineKey`、`dataset.metalPlateKey` |

另有**第四类需要单独判定**：`dataset.player` / `dataset.line` / `dataset.uid` / `dataset.defId` / `dataset.band` / `dataset.empty` / `dataset.metal` / `dataset.chainPlayer` 等——**它们本身是渲染器写在元素上的**（读取方是特效），所以属于 A 类；但若某个具体读取点是读特效自建节点上的键，则属于 B 类。**每个读取点都要按"这个元素是谁创建的"逐个判定，不能按属性名一刀切。**

## Task 1: 机读契约 `src/ui/fx-dom-contract.ts` + 守卫测试

**Files:**
- Create: `src/ui/fx-dom-contract.ts`
- Create: `tests/ui/fx-dom-contract.test.ts`

**Interfaces:**
- Consumes: 无
- Produces:
  - `type FxDomHookKind = 'attr' | 'class' | 'element'`
  - `interface FxDomHook { hook: string; kind: FxDomHookKind; category: 'A' | 'B' | 'C'; requiredBy: readonly string[]; note?: string }`
  - `const FX_DOM_CONTRACT: readonly FxDomHook[]`
  - `function hooksOfCategory(c: 'A' | 'B' | 'C'): FxDomHook[]`

**判定规则（逐条按此分类，不得按属性名一刀切）**

对每个 `querySelector` / `querySelectorAll` / `closest` / `dataset.*` / `getAttribute('data-*')` 读取点，问一句：**这个元素是谁创建的？**

- 由 `src/ui/render.ts`（或 G2 的远程页渲染器）创建 → **A 类**，`hook` 写成稳定选择器（属性选择器要写成 `[data-player]` 这种**不带具体值**的形式；值部分用 `="N"` 占位或省略）。
- 由特效层自己 `document.createElement` 创建 → **B 类**。
- 是特效挂在**任意**元素上的记账键（`dataset.*Key` 形态）→ **C 类**。

`requiredBy` 填**出处模块名**（如 `'fx-gen3.ts'`、`'gen3-control.ts'`、`'effects/index.ts'`），至少一项。

import { readFileSync } from 'node:fs';
import { fileURLToPath } from 'node:url';
import { FX_DOM_CONTRACT, hooksOfCategory } from '../../src/ui/fx-dom-contract';

/**
 * G1 守卫：FX DOM 契约必须「出处真实 + 现热座渲染器确实提供 + 分类互斥」。

const root = new URL('../../src/ui/', import.meta.url);
const read = (rel: string): string =>

  'fx-gen3.ts',

  'gen3-control.ts',

const fxSources = new Map(FX_MODULES.map((m) => [m, read(m)]));

describe('G1 · FX DOM 契约', () => {
  it('清单非空，且三类都出现过（防止只盘点了一类）', () => {
    expect(FX_DOM_CONTRACT.length).toBeGreaterThan(0);
    for (const c of ['A', 'B', 'C'] as const) expect(hooksOfCategory(c).length).toBeGreaterThan(0);
  });

  it('每条钩子都有 kind / category / requiredBy，且 requiredBy 指向真实存在的 FX 模块', () => {
    const names = new Set<string>(FX_MODULES);
    for (const h of FX_DOM_CONTRACT) {
      expect(h.hook.length, `空钩子：${JSON.stringify(h)}`).toBeGreaterThan(0);
      expect(['attr', 'class', 'element']).toContain(h.kind);
      expect(['A', 'B', 'C']).toContain(h.category);
      expect(h.requiredBy.length, `${h.hook} 的 requiredBy 为空`).toBeGreaterThan(0);
      for (const m of h.requiredBy) expect(names.has(m), `${h.hook} 的出处 ${m} 不在 FX_MODULES 内`).toBe(true);
    }

  it('钩子字符串不重复（同名钩子不得出现在两个分类里）', () => {
    const seen = new Map<string, string>();
    for (const h of FX_DOM_CONTRACT) {
      const prev = seen.get(h.hook);
      expect(prev, `钩子 ${h.hook} 重复登记（${prev} 与 ${h.category}）`).toBeUndefined();
      seen.set(h.hook, h.category);
    }
  });

  it('A 类钩子必须真的被某个 FX 模块引用（防止凭空发明）', () => {
    const missing: string[] = [];
    for (const h of hooksOfCategory('A')) {
      // 取钩子的「判别子串」：属性名或类名，去掉值与 CSS 语法
      const probe = h.hook.includes('[') ? /\[([a-z-]+)/.exec(h.hook)?.[1] ?? h.hook : h.hook.replace(/^\./, '');

      if (!hit) missing.push(`${h.hook}（判别子串 ${probe} 未在任何 FX 模块中出现）`);

      '.deck[data-player]',
      'protocol-img',

      'play-btns',
      'control-track',
    ]) {
      expect(all, `核心钩子 ${core} 未登记`).toContain(core);
    }
  });
});

```ts
/**
 * FX DOM 契约（G1；见 docs/2026-09-13-联机与多端-设计稿.md §6.3）。
 *
 * 特效层通过选择器/数据属性依赖渲染器产出的 DOM。G2 要重写远程对战页面，
 * 这份清单就是那份「远程页必须提供」的验收基准 —— 少一项就会有整条点名特效静默不播
 * （本项目历史上已发生过多次，见 docs/3代特效-进度与上下文.md §0）。
 *
 * 分类（判定规则见 docs/4代-FX DOM 契约.md）：
 *  A 结构钩子：渲染器产出、特效只读用于定位 → 远程页必须提供
 *  B 特效自建节点：特效自己 createElement 后取回 → 渲染器无需提供
 *  C 内部注册键：特效挂在元素上的记账 dataset 键 → 渲染器无需提供
 */

export type FxDomHookKind = 'attr' | 'class' | 'element';

export interface FxDomHook {
  /** 稳定选择器（属性选择器不带具体值，如 `.deck[data-player]`） */
  hook: string;
  kind: FxDomHookKind;
  category: 'A' | 'B' | 'C';
  /** 出处模块名（见 tests/ui/fx-dom-contract.test.ts 的 FX_MODULES） */
  requiredBy: readonly string[];
  /** 一句话：这个钩子供什么特效定位用 */
  note?: string;
}

export const FX_DOM_CONTRACT: readonly FxDomHook[] = [
  // —— A 结构钩子（远程页必须提供）——
  { hook: '.stack-slot[data-player][data-line]', kind: 'class', category: 'A', requiredBy: ['fx-gen3.ts'], note: '链路槽几何：3 代飞行/连接件的落点（slotRectOf / lineCenterX）' },
  { hook: '[data-uid]', kind: 'attr', category: 'A', requiredBy: ['gen3-util.ts'], note: '按 uid 取卡节点 rect（nodeOf → visibleRectOf / clipInsetRightPct）' },
  { hook: '.deck[data-player]', kind: 'class', category: 'A', requiredBy: ['effects/index.ts'], note: '牌库位置（deckPos）' },
  // …按规则穷举补全…
];

/** 取某分类的全部钩子 */
export function hooksOfCategory(c: 'A' | 'B' | 'C'): FxDomHook[] {
  return FX_DOM_CONTRACT.filter((h) => h.category === c);
}
```
