## 2. 三条铁律（违反会直接出 bug）

1. **叠加不替换**：基础动画永远照播（切割 / 碎裂 / 翻面 / 幽灵飞行 / 卡背飞行）；协议特效只加层。
   需要"慢一点"时用**可选时长参数**（`playFlip(…, 750)` / `playDeckPlay(p, 700)`），**不要**改默认值。
2. **常驻 ≠ 瞬态**：
   - 单次触发 → 事件订阅 + body 级浮层（z 301/620），播完 `remove()`；
   - "持续生效中" → `sync*` 常驻层（z 46~49），**签名短路 + 只重定位不重建**（重建会重启动画）。
3. **被覆盖卡只在可见区域播放**：用 `visibleRectOf(s, uid)`（同步层）或 `clipInsetRightPct(s, uid)`（浮层卡 `clip-path`）。
   链路里新牌沿"从协议向外"横向重叠铺开，被盖卡露出的永远是**左侧一条**。

## 5. 常见改法（照着做）

### 5.1 给某个协议加一条"某动作触发"的附加层
1. 在 `fx-gen3.ts` 的 `GEN3_CARD_FX_COVER` 对应动作集合里加上协议名（**守卫测试会核对这份清单**）；
2. 在对应 `gen3XxxFx` 的 switch 里加分支：
   - 需要"前置段 → 延后基础动画"：照 `greed`/`gluttony` 的 `finish(preMs, cls)` 写法；
   - 即时叠加：`api.playCut(…)` / `api.playShatterAt(…)` / `api.playFlip(…)` / `api.playShift(…)` 照常调用；
3. 在 `styles-gen3-cards.css` 里加 `g3-*` 样式与关键帧；
4. 跑 `npx vitest run tests/ui/gen3-card-fx.test.ts`（类名↔CSS 会立刻报错，这很好）。

### 5.2 加一个"持续生效中"的常驻层
照 `gen3-control.ts` 里任一 sync 写：算条件 → 算"签名" → 相同只 `place()`、不同才重建 → **返回 active 键**；
不要自己 prune（统一由 `syncGen3Persistent` 处理）；样式加进 `styles-gen3-sync.css`（z=46/48/49）。

### 5.3 加一套"协议已编译"特效
`compiled-gen3.ts` 加 `append<协议>(layer, defId, api)` + 在 `appendGen3CompiledFx` 挂 case；
CSS 加 `.protocol.compiled-fx-<proto>`、`.compiled-ring-<proto>`（含呼吸动画 + 隐藏 `.lava-seg/.lava-rock`）、
`.compiled-<proto>-corner`（`--cc/--ccg`）+ 元素样式；主题色加进 `protocol-colors.ts`。

## 6. 坑清单（都踩过，别再踩）

1. **浮层卡自身的 `background` / `::before` 会被卡面 `<img>` 盖住** → 覆盖类视觉一律走 `::after` 或子元素。
2. **浮层卡类上不要做 `transform` 动画**（会覆盖横置卡 `rot-cw/ccw` 的内联 `rotate`，卡会"立起来"）
   → 位移交给子元素（粒子用 `--dx/--dy`，角度用 `--r` + keyframes 内的 `rotate(var(--r))`）。
3. **JS 建了元素但 CSS 没定义类 → 特效静默消失**（tsc/vitest 都不报错）→ 守卫测试专治这条，**每批都靠它抓到真实遗漏**（A:5、B:0、C:7、D:11）。
4. **共用基础函数不要做全局字符串替换**：给 `playDeckPlay` 加时长参数时把 `MOVE_MS` 全局替换 → 连带改到
   gravity/speed 等 5 处（靠 tsc `Cannot find name 'durationMs'` 抓回）。改共用函数要**逐处精确替换**。
5. **常驻层重建 = 动画重启**：即使条件没变也要先比签名，只重定位。
6. **各 sync 不要自己 prune**：会互相删层（本批写错过一次）。统一 `syncPrune`。
7. **`card:drawn` 没有 uid**：必须在 `if (!payload?.uid || !payload.defId) return;` **之前**处理。
8. **PowerShell here-string 里写 TS 模板串 `${…}` 会被当变量插值**：改动含模板串的代码请用编辑工具，别用 here-string。
9. **`git add -A` 会扫到仓库里原有的第三方目录**（`其他人制作的版本/`）→ 一律 `git add src tests docs`。
10. **覆盖表写了 ≠ 实现了**（批次 F 的三个"特效从不出现"全是这条）：`GEN3_CARD_FX_COVER` 里列了协议，
    但函数内没有对应 `case`（嫉妒3 反打）、或整个函数都不存在（贪婪2 回手）、或事件根本没有分发分支
    （`card:played`）。→ 现在守卫会逐条断言「覆盖表每一项 ⇒ 对应函数内真的有实现」+「每个导出的 `gen3*Fx` 都被分发器调用」。
11. **延迟播放必须用"事件时定格的 rect"**：`queueStaggered` / `setTimeout` 回调里再 `geom(node)` 会拿到 null
    （DOM 已被重渲染替换）→ 特效静默不出现（新星0 整线删除、愤怒2 整线翻转都踩过）。
12. **引擎在 emit 之前清空的字段 = payload 里拿不到**：`card:deleted` 的 `line`/`pos`、`card:returned` 的 `line`
    都是这样（前者已在批次 F 回填，后者只能靠 `owner`+`triggerUid` 定位）。
13. **效果栈挂起期间不能用普通 action**：`rearrange-protocols` 在 `pendingEffects` 非空时被硬拒 →
    效果内重排必须走 `effect-choice` + draft 模式（批次 F #10）。

## 8. 品质标准（做新特效时逐条自查）

见设计稿 §8：**七要件**（层次合成 / 材质 / 物理感 / 三阶配色 / 起止衔接 / 与基础动画咬合 / 可读性）
+ **禁止清单**（单一 opacity 闪烁、纯色块平移、全程 linear、突然出现消失、只换色不换语法、一个光晕撑全场）。
一句话检验：**把这条特效截一张静止图，能不能看出"这是什么协议在做什么事"**；看不出就是塑料。
