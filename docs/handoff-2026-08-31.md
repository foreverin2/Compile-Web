## 1. 环境 Runbook（每条派发都必须带上——违反即坏）

- 不要修改 `vite.config.ts` 的 `test.pool`（必须保持 `'threads'`）。
- 禁止 `npm install` / `npm ci`（node_modules 有本地 vite 补丁；确实要装时用 `--cache node_modules/.npm-cache`）。
- 测试：`npm test` 或 `npx vitest run tests/<file>.test.ts`。测试 import 规则：`tests/<子目录>/` 用 `'../../src/...'`（两层）；`tests/helpers.ts` 用 `'../src/...'`。
- TypeScript strict，禁止 `any`。每任务提交一次；**推送需用户明确指示**。
- 推送时若 git 代理（`127.0.0.1:7890`）失效，用直连绕过：
  `git -c http.proxy= -c https.proxy= -c "http.https://github.com.proxy=" -c "https.https://github.com.proxy=" push origin main`

## 4. 引擎能力清单（新机制，开发/修 bug 必读）

- **Op**：discard/discardMany（批量，after-discard 一次）/delete/return/flip/shift/playTopDeck(player/belowUid)/playFromHand/draw(player/fromOpponentDeck)/reveal/rearrangeProtocols(player)/give/takeRandom。playTopDeck **不洗弃牌堆**（FAQ 142）。
- **触发**：before-covered / before-flip（flip op 前置，metal-6）/ before-compile（executeCompileUnchecked，pendingCompile 机制）/ after-draw / after-discard（弃牌者对手）/ after-delete（被删卡持有者，**不含编译删除**）/ after-clear-cache / end / start。after-* 由 fireReactive 即时 push（topCommand 跳过未覆盖检查）。
- **被动限制**（restrictions.ts 纯查询 + getLegalActions/playCard 双守卫）：spirit-1 任意线、psychic-1 对手只能反面、plague-0 禁此列、metal-2 禁此列反面、spirit-0 跳过缓存、apathy-2 无效化线中指令、metal-1 compileBlocked（被禁玩家回合结束清除）。
- **其他**：chooser（选择权）、top 标志（被盖仍生效）、cardPointValue（正面=牌面/反面=2或暗2线4/牌库2）、secret 卡（进手牌即解禁）、fizzle（空候选自动续接）、sourceValid、**尽力而为弃牌约定**（弃 N 张不足弃全部剩余，空跳过，后续指令照常——用户拍板全局）。

## 5. 官方 FAQ 关键裁决（本阶段依据，后续协议/勘误必查 `compileFAQ文本.txt`）
