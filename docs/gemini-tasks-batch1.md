# Gemini 素材生成任务单（阶段 1.5 — 首批）

> 用法：每张任务单独立复制发给 Gemini。生成物按「交付路径」放回项目后，我来接入。
> 当前技术栈：纯 HTML/CSS/JS（Vite + TS）。**所有素材必须是 CSS / SVG / Web Animations / PNG 之一**，无外部依赖、无插件。

---

## 任务单 A：游戏背景场景（首屏氛围）

### 任务
为 Compile《译世界》生成一个网页游戏背景场景（静态氛围图或 CSS 场景），风格为"黑暗赛博虚空 / 觉醒 AI"主题。

### 技术规格
- 交付格式：**PNG（1920×1080 或更大，作为 CSS background-image）** 或 **纯 CSS 渐变+图形组合**（二选一，推荐 CSS 组合：零体积、无限缩放）
- 文件命名：`bg-scene`
- 交付路径：`public/assets/bg-scene.png`（PNG 方案）或直接给 CSS 代码（接入 `src/ui/styles.css` 的 `body` 背景）
- 导入方式：CSS `body { background: ... }`

### 视觉描述
- 主题：**废弃的数据虚空**。深黑蓝底色（#0a0e1a → #1a1a2e 渐变），远处有模糊的数字雨/数据流
- 中央偏下有微弱的网格地平线（赛博空间感），角落有淡淡的荧光青色（#00ffcc）与品红（#ff00aa）辉光
- 氛围：冷静、神秘、科技感；是"两个 AI 争夺改写现实权限"的舞台
- 不要有人物、不要有文字；画面留暗，作为卡牌游戏的衬底（对比度低，不干扰前景卡牌）
- 参考意象：电影《创：战纪》的网格空间、赛博朋克 2077 的夜间城市但更抽象

### 约束
- 简洁可用即可；低对比度、暗色系，前景是亮色卡牌
- 无外部依赖

### 交付物清单
- [ ] `public/assets/bg-scene.png` 或 CSS 背景代码

## 任务单 B：牌桌材质（对战区域衬底）

### 任务
生成对战区域的"牌桌"材质——中间 6 个协议槽的公共区域背景。

### 技术规格
- 交付格式：**PNG（1200×600 透明底）** 或 CSS
- 文件命名：`table-mid`
- 交付路径：`public/assets/table-mid.png`
- 导入方式：`.midline` / 协议槽区域的 `background-image`

### 视觉描述
- 一条水平的"数据工作台"条纹，横贯场地中央（对应 3 条线路的公共协议区）
- 深色半透明玻璃质感（深蓝灰 #141a2e），带细微的电路板纹理或六边形网格暗纹
- 中间区域比两侧略亮，暗示"协议核心区"；边缘有荧光描边（青 #00ffcc 半透明）
- 不需要卡槽具体格子（格子用 CSS 画），只需材质衬底

### 约束
- 低对比度；透明 PNG 或 CSS 均可

### 交付物清单
- [ ] `public/assets/table-mid.png` 或 CSS

## 任务单 C：火焰焚烧特效（Fire 协议专属，阶段 2 用）

### 任务
生成"火焰焚烧"卡牌特效：当 Fire 协议的卡牌被弃置/删除时播放的焚烧动画。**这是阶段 2 的占位素材，现在先产出，本轮只接入静态版本。**

### 技术规格
- 交付格式：**Lottie JSON** 或 **CSS @keyframes + 粒子 div** 或 **SVG 动画**（推荐 CSS/SVG：免插件）
- 动画时长：≤ 1.2s，单次播放（焚烧是终结动作）
- 文件命名：`fire-burn`
- 交付路径：`public/assets/fire/fire-burn.css`（或 .json / .svg）
- 导入方式：`src/ui/effects/` 注册到 `fire:discard` / `fire:delete` 命名空间

### 视觉描述
- 卡牌表面自下而上燃起火焰：橙红（#ff6b00）→ 金黄（#ffd000）→ 暗红（#c41e00）渐变
- 火焰形态：多簇向上摇曳的粒子/火舌，边缘有黑烟（#1a1a1a）与火星（亮橙小点飞散）
- 焚烧结束：卡牌区域短暂残影（半透明轮廓）后淡出
- 风格写实偏 stylized，与暗色赛博背景协调（火焰是场上唯一高饱和元素）

### 约束
- 免插件；1.2s 内完成；可接受简化版（先出火舌+火星即可）

### 交付物清单
- [ ] `public/assets/fire/fire-burn.css`（含 @keyframes 与粒子结构说明）

## 任务单 D：协议卡 Loading 面（占位美术）

### 任务
为 6 套演示协议（水/火/光/暗/生/死）的"加载中"协议卡面生成占位美术——卡片中央显示协议名 + 关键词图标。

### 技术规格
- 交付格式：**PNG（300×420 每张）** 或 **CSS/SVG 模板 + 文字覆盖**
- 文件命名：`protocol-<name>-loading`（name = water/fire/light/darkness/life/death）
- 交付路径：`public/assets/protocols/`
- 导入方式：`renderProtocol` 中 protocol 卡片的背景

### 视觉描述
- 每张协议卡 = 深色卡底（与卡背同系） + 中央大号协议图标（水=水滴波纹、火=火焰、光=放射光线、暗=黑色漩涡、生=嫩芽/细胞、死=骷髅/沙漏）
- 图标下方留空位（游戏内文字覆盖协议名）
- 卡片四角有细荧光描边（各协议一个主题色：水青 #00ccff、火橙 #ff6b00、光金 #ffd000、暗紫 #7a00ff、生绿 #00ff88、死灰 #888888）
- 风格：简洁矢量图标风，不要过度写实

### 约束
- 图标清晰可辨；留出文字空间；6 张风格统一

### 交付物清单
- [ ] `public/assets/protocols/protocol-water-loading.png` …（共 6 张，或 1 个 SVG 模板）
