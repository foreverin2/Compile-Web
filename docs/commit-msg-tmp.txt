fix(规则): 嫉妒0 只能加持有者自己的阈值（对手不再被错误加成）

用户实测指出：对方不会触发嫉妒0 的效果、不该被加那条链路的阈值。

根因（规则 bug）：
- envy-0 顶框值修正注册成了 `valueModifier target: 'line'`。引擎 stackValue 里 line 的语义是
  "线上任一玩家链路的正面修正卡对【双方估值】都生效（对每个估值方各应用一次）"——这与
  lust-0「每位玩家在此链路的总阈值增加10」、wrath-0「所有最高阈值的牌不计入玩家的总阈值」相符，
  但与 envy-0 卡文不符：「此链路中，【你的】总阈值增加对手在此链路中最高阈值卡牌的阈值」= 只加卡主自己。
  结果：对手也被加上"你链路上的最高阈值"。
- 错误的根源是 docs/3代-批1-规格与裁决清单.md 当时把实现规格写成了 target=line（已同步更正）。

修法：
- src/core/effects/cards/envy.ts → valueModifier 改用 target: 'own-stack'。
  own-stack 下仅当估值方==卡主时应用，apply 的 owner=卡主 → 加的是卡主【对手】堆叠全部卡
  （含被盖/反面，按当前点数值）中的最大者；对手该链无卡 → +0。faceUp 才生效（引擎自动）。
- 同族另两条 line 修正卡（darkness-2「所有此栈的反面牌分值为4」、lust-0「每位玩家+10」）经逐条核对
  确属双方语义，保持不动；wrath-0 亦为双方语义（此前已与你确认），保持不动。

测试：
- tests/effects/gen3-batch1-cards.test.ts 新增区分性回归：P2 持有嫉妒0 且该线还有一张 4、P1 该线为 1
  → 断言 P2 = 4+1、P1 = 1（旧实现会错误得到 1+4=5）。
- tests/effects/gen3-batch3-cards.test.ts 中固化旧行为的断言（P1 估值 3+4）已更正为 3。

文档：裁决清单该行改为 target=own-stack 并注明更正原因；设计稿 E1 行补"只加持有者"；
进度文件新增 Bug 3 记录（含"特效侧无需改：syncEnvy0Absorb 本来就是按持有者算"）。
