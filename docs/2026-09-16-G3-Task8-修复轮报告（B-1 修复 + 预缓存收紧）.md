## 重要 2（I-3）预缓存范围与 install 失败 —— **已按设计稿收紧 + 失败不静默 + S-4 顺手收掉**

### 改了什么（三条）

**(a) 预缓存收紧到 app shell（设计稿 §8.1 原话）。** `scripts/gen-sw-manifest.mjs` 里加了一条
**纯函数**判据（从内容派生，没有手写文件名清单）：

```js
const SHELL_EXT = /\.(html|js|mjs|css|json|webmanifest)$/i;
const ICON_DIR = 'icons';
export function isShellAsset(rel) {
  const segs = rel.split('/').filter(Boolean);
  if (segs.length > 1 && segs[0] === ICON_DIR) return true;   // PWA 安装图标必须离线可用
  return SHELL_EXT.test(rel);                                 // 与目录无关：vite 的 assets/index-*.js|css 就是 shell
}
```

⇒ 卡图（`assets/protocols/**`）、规则 PDF（`assets/rules/**`）、音效、`assets/battery/**`
（`.gitignore:4` 标的未使用电池图）**全部不预缓存**；它们仍走运行时 `fetch`（缓存优先、未命中走网络）。

> 我第一版把 `EXCLUDE_DIRS` 写成 `['assets',…]` 并按段排除 —— **实测会把 `assets/index-<hash>.js`
> 这个 app shell 本体也排掉**（仓内既有的对照腿 `expect(manifest.files.some(f => f.startsWith('/assets/') && f.endsWith('.js')))` 当场变红），
> 已改成上面的后缀白名单 + `icons/` 例外。

**(b) install 失败不静默。** `public/sw.js` 的 install：

```js
try {
  const res = await fetch(MANIFEST_URL, { cache: 'no-store' });
  if (!res.ok) throw new Error(`sw-manifest.json 取不到（HTTP ${res.status}）`);
  const manifest = await res.json();
  CURRENT_VERSION = manifest.version;
  const cache = await caches.open(CACHE_PREFIX + manifest.version);
  await cache.addAll(manifest.files);
  await writeMarker(cache, manifest.version);      // 全部成功后才写版本标记
} catch (e) {
  await notifyCacheIncomplete(e instanceof Error ? e.message : String(e));   // ① 广播给所有页面窗口
  throw e;                                                                   // ② 让这次 install 失败
}
```

页面侧（`pwa-update.ts`）**新增 `message` 通路**：`SW_CACHE_INCOMPLETE`（常量，`sw.js` 里同名
字面量，有腿断言两边逐字一致）⇒ 状态机新增事件 `cache-incomplete` ⇒ 落到
`{ kind: 'failed', phase: 'install', reason }`，并经新的 `PwaEnv.onCacheIncomplete?` 出口暴露；
真实环境默认用 `console.warn` 兜住。**刻意不做任何刷新**（新 SW 没装好时旧 SW 仍在控制页面，
刷新既没用又打断对局）。**也不 throw 整个 install 而不通知** —— 两条都做：先通知，再失败。

**(c) S-4（`CURRENT_VERSION` 为 null ⇒ `compile-null` 删光）**：activate 不再用模块级变量拼缓存名，
改成**只认"带版本标记的缓存"**：版本号随预缓存一起写进缓存（`VERSION_MARKER = './sw-version'`，
