## §6 本阶段新增的方法论教训（已全部写进计划 §2 第 13-15 条）

1. **变异证据的四个陷阱**（T1 全踩过）：① 镜像 `include` 相对 `test.root` 解析，匹配不到就以
   `No test files found` 退 1 ⇒"缺陷复现"与"什么都没跑"退出码同形；② 探针的输入必须落在
   **被变异的那条路径**上（T1 的 M1 变异是对调第 1、2 步，探针却只违反一条 ⇒ 两个世界都全绿）；
   ③ 备份别"只在缺失时创建"，否则中途改源码后 `--restore` 会把旧版灌回镜像、在**旧基线**上静默跑完；
   ④ 证据别用单一可覆盖槽位（`out-M2-*.txt` 被下一批原地覆盖），要每批一个不可变目录。
2. **夹具必须能自证会红**：CDP 夹具的 `--self-check` 会**故意不转发 answer**，宿主必须连不上；
   没有这条反向证明，夹具可能只是空转。
3. **同一个值别承载两个含义**：`'read-only'` 在原契约里精确指"`dispose()` 之后"，
   掉线要用新增的 `'offline'`（D16）。本仓为"一个字段两个含义"吃过阻断级修复。
4. **栈里没有 `@types/node`**：`tests/**` 能用的 `node:*` 面由 `tests/node-types.d.ts` 手写限定
   （`node:path` **只有 `join`**）。新增声明前先读 `tests/app/match-file.test.ts:669-671` 的现行规则。
5. **镜像里探针的相对 import 不许越出 root**（T1 阶段一评审自己踩的）：vitest 把以 `../` 开头的
   说明符当成**从 root 起算**，`'../../../src/net/protocol'` 会逃出镜像、**静默读到共享树的干净
   源码**，于是"该红不红、全绿"。抓法是往镜像那份源码插一个只在镜像里存在的 marker 用探针打印
   （读到 `undefined` 就是错了）。⇒ **光看 `RUN vX <root>` 是镜像不够。**
6. **"覆盖面 / 完整性"型的自证必须从样本反推**：T1 的 `REAL_FILE_REQUIRED` 是手写清单，
   加一条没有真文件样本的禁项时**判据面 37 条 + 探针面 24 条全绿** —— "忘了同步"是必然漏、
   不是概率漏。要让"表里的标签集合"与"样本实际打中的标签 ∪ 显式豁免集"相等，这样加/删都会红。
   同族提醒：写防御性断言前先问"它在什么世界里会红"（T1 有一条"反向断言"恒真）。
7. **T3/T4 又添了一批，这里不重抄，只列条目标题**（全在计划 §2 第 14/15 条）：
   跨阶段陈旧备份静默换掉判据、`exit≠0` 却 0 条失败用例属硬错误、守卫裸词匹配会命中字符串字面量、
   `fs.cpSync` 打崩 Node、vitest 把绝对 `include` 匹配成零文件、`--restore` 要从共享树重取、
   **探针 JSDoc 里照抄 vitest 通配符会提前终止注释（新变体：文件在、用例 0）**、
   **vitest 与 tsc 解析相对路径口径不一致（镜像自证要两个工具各证一遍）**、
   `spawnSync('npx.cmd')` EINVAL 与 `cmd /c mklink` 中文路径静默失败、
   **"探针收集 N"必须给路径 + 收集数 + 命令三元组（不可复算的数字等于没有）**、
   以及**文本腿不是行为腿的附庸**（T4 实证：另写一份语义相同的映射，行为腿一次都不红）。
