# Gemini 生成任务单：卡牌「删去」特效（破碎消散）

> 用法：把本文件内容发给 Gemini，生成物按「交付路径」放回项目。

## 任务
为一个纯 HTML/JS 网页卡牌游戏生成「删去」特效代码：场上的卡牌被删除时，卡面**破碎成多块碎片、向外飞散并逐渐消失**。这是所有协议的通用基础特效（Fire 协议另有专属火焰特效，互不影响）。

## 技术规格
- 交付格式：**纯 CSS + 原生 JS**（无框架、无外部依赖、免插件）
- 文件命名与交付路径：
  - `public/assets/fx/delete-shatter.css`
  - `public/assets/fx/delete-shatter.js`
- 导入方式：CSS 由 `index.html` 以 `<link>` 引入；JS 由宿主（`src/ui/effects/index.ts`）`import` 并调用
- 动画时长：**≤ 1.2s**，单次播放（非循环）

## 宿主集成契约（必须遵守，宿主按此调用）
1. 触发时，宿主把被删卡牌克隆到 `document.body` 级浮层（`position: fixed` 定位到原卡位置，`pointer-events: none`），克隆节点保留 `.card` 类与卡面图片子节点，**不含交互按钮**。
2. 宿主在克隆节点上调用你提供的挂载函数，例如：
   ```js
   import { mountShatter } from '/assets/fx/delete-shatter.js';
   mountShatter(cardCloneNode); // 内部给节点加 .card-shattering 类 + 挂载碎片覆盖层并启动动画
   ```
3. 你提供的 JS 需**自行生成碎片**：把卡面切成 8~12 块多边形碎片（建议用 `clip-path` 或绝对定位小矩形 + 旋转），碎片从原位向外飞散（位移 + 旋转 + 轻微缩放），整体透明度渐隐至 0。
4. **动画结束由宿主负责移除**（约 1.2s 后），你的代码只需保证动画在 1.2s 内自然结束，不要自己移除节点。
5. 不要在代码里引入任何网络资源、字体、图片。

## 视觉描述
- 卡面受击碎裂：裂纹先出现（可加 1~2 帧白色闪光表示"碎裂瞬间"），随后碎片向外飞散
- 碎片带轻微旋转与翻滚，轨迹呈放射状（圆心=卡牌中心）
- 配色与氛围：冷色系（青蓝白）闪光 + 碎片渐隐，契合游戏的赛博/程序代码风格（现有 UI 主色 #4ff0ff 青、#0a0e1a 深底）；不要用火焰橙红色（那是 Fire 协议专属）
- 可加少量粒子（细碎光点）伴随碎片消散，数量 ≤ 20，避免性能负担

## 约束
- 无需真实美术功底，简洁可用即可；所有尺寸相对卡牌节点自适应（用 % 或基于节点尺寸计算）
- 无外部依赖/免插件；动画时长 ≤ 1.2s；不自己移除节点；不触碰宿主逻辑
- 代码注释用中文
