# Gemini 生成任务单：草案 → 游玩页加载切屏视频

> 用法：把本文件内容发给 Gemini，生成视频文件后放回项目（路径见下）。

## 任务
为一款赛博风格的双人卡牌网页游戏生成一段 **2~3 秒的加载切屏视频**：玩家完成协议选牌（草案）后、进入对战界面前的过渡画面。风格需与游戏现有 UI 一致（深色底 + 青色霓虹）。

## 技术规格
- 交付格式：**视频**（MP4，建议 1920×1080，30fps；若工具只出 GIF/WebM 也可，注明实际格式）
- 时长：**2~3 秒**，末尾画面静止稳定（用于切到游戏界面的衔接，避免突变）
- 文件命名与交付路径：`public/assets/ui/loading-transition.mp4`（或 .webm/.gif）
- 用途：草案完成后全屏播放该视频 → 结束后渲染对战界面（宿主在视频播放完毕后切屏，请确保视频有明确的结束帧）

## 视觉描述
- 整体氛围：**赛博 / 程序代码风格**，与游戏一致——深色近黑底（`#0a0e1a` 类）、青色霓虹光（`#4ff0ff` 类）、细扫描线/网格底纹、少量漂浮的代码字符粒子（如 `0` `1` `< >` `{ }`）
- 开场（0~0.5s）：黑暗中出现中央聚焦的光点/代码流汇聚
- 中段（0.5~2s）：一组**卡牌轮廓**（透明线框，数量 3~6 张，可隐约呈现协议卡轮廓）从屏幕四周/底部依次飞入并排列成行，卡牌边缘青色发光，伴随"加载中 / COMPILING PROTOCOLS"风格的英文字样或中文"协议编译中"（若工具不支持中文渲染就用英文 `COMPILING PROTOCOLS...`）
- 收尾（2~3s）：卡牌排列定格、光效收敛、整体略微变暗，为进入游戏界面做准备；**结尾 0.3s 保持静止**（避免突兀）
- 不要出现游戏 logo、不要出现真人、不要大段文字（至多一行加载提示）

## 约束
- 无外部素材依赖（全部由生成工具渲染）；无音频要求（可无音轨，或极轻的环境音效）
- 风格克制：不要花哨过度，服务于"加载过渡"功能
- 若视频无法生成，退而求其次生成**动画 GIF**（同样 2~3s、可循环）并在交付物清单注明

## 交付物清单
- [ ] `loading-transition.mp4`（或 .webm/.gif，注明实际格式与分辨率）
- [ ] 简短说明：时长、分辨率、帧率、结束帧是否静止、是否带音轨
